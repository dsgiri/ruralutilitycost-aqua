# Site Architecture & URL Map

## Directory Structure
- `/src/pages`: Main application routes (Home, Legal, About).
- `/src/pages/tools`: Calculator specific pages.
- `/src/components`: Reusable UI elements (Layout, ToolCard, SEO, Disclaimer).
- `/src/lib`: Utility functions.
- `/docs`: Project documentation.

## URL Map
- `/`: Home Dashboard
- `/tools/estimate`: Cost Estimator
- `/tools/feed`: Feed & FCR Calculator
- `/tools/harvest`: Harvest Calculator
- `/tools/profit`: Profit & Breakeven
- `/tools/compare`: System Comparison
- `/favorites`: User Favorites
- `/about`: About Page
- `/contact`: Contact Us
- `/legal`: Legal & Disclaimer
- `/privacy`: Privacy Policy
- `/terms`: Terms of Service
