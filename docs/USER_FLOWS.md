# User Flows & Journey Maps

## Persona: Aquaculture Operator

### Flow 1: Evaluating a New Pond Setup
1. **Entry**: User lands on `/` (Home).
2. **Action**: Clicks "Cost Estimator".
3. **Engagement**: Fills out Pond size, stocking density, and variable costs. Input is saved to local storage.
4. **Result**: Views Total Capital and Operating Costs on the sticky right panel. Reads the disclaimer.
5. **Next Step**: Navigates to "Profit Calculator" to determine breakeven price based on the generated costs.

### Flow 2: Comparing Systems
1. **Entry**: User navigates to `/tools/compare`.
2. **Action**: Enters parameters for "Intensive RAS" vs "Extensive Pond".
3. **Result**: Views Recharts bar chart showing net profit differences.
4. **Action**: Bookmarks the page or relies on local storage to persist the scenario for a later meeting.
