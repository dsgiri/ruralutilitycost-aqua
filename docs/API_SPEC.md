# API & Integrations Spec

## Third-Party Integrations

1. **Google Analytics (gtag.js)**
   - Used for page views, click events, and scroll tracking.
   - Measurement ID: `G-RG4VV8TP1E`.

2. **Google AdSense**
   - Placeholders implemented via `<AdSensePlaceholder />`. (Currently removed but structurally documented).

3. **Stripe (Planned/Potential)**
   - For premium financial modeling subscriptions.

4. **Resend (Planned/Potential)**
   - For transactional emails (e.g., emailing PDF reports of calculation scenarios).

5. **GIA / External APIs (Planned/Potential)**
   - Specialized integrations mentioned in prompts for expansion.
