# Email Templates Spec

*(Note: Currently, Aqua is a client-side calculator hub. If email functionality is added, the following applies.)*

## Transactional Emails

### 1. Scenario Export
- **Trigger**: User requests a PDF report of their profit/loss calculator.
- **Content**: Summary of inputs, outputs, charts, and attached PDF. Includes standard Disclaimer.

### 2. Verification / Claims
- **Trigger**: User claims a specific farm asset or enterprise subscription.
- **Content**: Magic link to verify identity and activate premium features.
